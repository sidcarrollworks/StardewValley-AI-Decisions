Fixed intention, different voices

The scene and intended action stay fixed. The same generator writes private thoughts with a character profile, then with actual character dialogue added as wording references. Authored alternatives give us something to judge against.

Read for meaning first: does the thought still plan the same act, for the same person and reason? Then compare rhythm, vocabulary and attitude with the source. Valid JSON is a format check. It says nothing about whether this sounds like Vincent, Maru or George.

Open a wording trial JSON file, or use a prepared comparison.
