Runner setup
Double-click Start Under Glass.cmd in the checkout. Or run pwsh -File sim/tools/start-preview.ps1 -Open. Choose a preset, then Start required servers. Healthy existing servers are reused. The preview can stop only servers it started; stopping the preview stops those servers too.
First-time dependencies and model weights must already be installed. The launcher uses sidecar/.venv from this checkout or its main checkout; set UNDER_GLASS_PYTHON to override it. Haiku uses ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN, UNDER_GLASS_ANTHROPIC_KEY_FILE, or your existing ~/.anthropic/api-key.txt. Keys stay outside the page and recordings. Health checks do not send inference requests.
The local server builds Replay once at startup. Restart it after simulation changes. All Replay flags are available, including numeric/boolean overrides. Their defaults describe the shipped town before other flags are applied.
For Newcomer testing, export the Speech editor catalog, upload it under Speech and enable the Newcomer test voice. For character context, export Archetype Studio's pack and upload it under Mind.
Generation speed and playback speed are separate. Fewer reflection/dream opportunities reduce model calls but change the experiment. Tape mode reuses recorded answers without live model calls, for compatible settings.
