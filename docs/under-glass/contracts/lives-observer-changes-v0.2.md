# Lives observer contract: changes from 0.1 to 0.2, and the implementation sequence

Proposed 2026-10-14 for Sid's fifth direction (section 3). 0.1 stays frozen; nothing is implemented.

**The adapter read.** Codex's 0.1 chain adapter on `codex/lives-chain-viewer` (PR #95) at **aef9d7f** ("Pause on event
selection and resume following on Play", 2026-10-14 18:26), the branch head and `origin`'s, a clean worktree when read:
`sim/viewer/chains-model.js` (**CM**), `chains.js` (**CJ**), `sim/tools/test-chains.cjs` (**T**, 38 tests). Line numbers
are aef9d7f's. CM:19 refuses every version but `"0.1"`, so no 0.2 file reaches the reads below today: each row says
what a 0.2 adapter must do. Each read was confirmed by running CM on the 0.2 fixture with its version set to `"0.1"`,
and re-run on the regenerated summer 3-4 fixture (the ids and `seq` values below are its).

**Impact.** **none**: nothing CM reads changed. **additive**: new fields or reader rules; nothing CM reads moved or
changed meaning, so it runs as before, and conforming needs only the work named. **breaking**: a path CM reads moved or
changed meaning, so it shows nothing, shows the wrong thing, or throws. Breaking rows are for Sid and Codex to agree
before Codex replaces its 0.1 adapter; nothing here edits Codex's files. "Why" cites the direction by item (5.3 is the
fifth direction's item 3), a code fact, or a review.

**Deviations from the lead's decisions, for Sid to see.**
- D2: an outcome's `world` and `determinedBy.rule` stay at the top level as codes. Outcomes are an observer-only table,
  so nothing there reaches a character; prose (`determinedBy` text, `settledLabel`) is under `observer`.
- D2: the per-viewer projection of attempts and shared records is a declared rule (contract 4.2's last column), not a
  data split: a reader that only hides `observer.*` still shows a perceiver the actor's own fields. Moving them into an
  actor-only object was the alternative; it is open for Codex and Sid.
- D5: `asked` cannot be the not-asked flag (it holds a name); it is `askMade`.
- D3/D8: a `characterLabel` and a tape's free text are not machine-verified beyond verbatim secrets, typed ids and
  kinship voice on shared records; they need review, and the pilot adds a writer test for request text.
